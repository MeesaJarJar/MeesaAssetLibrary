Publishes to main

Kept in this tab's sessionStorage only. It is sent only to api.github.com and is never placed in the URL or logged. Create a fine-grained token.

Read access to the repository is checked before publishing is enabled.
How to create the token
  1. Open github.com/settings/personal-access-tokens/new.
  2. Set Repository access to Only select repositories, then choose MeesaAssetLibrary.
  3. Under Permissions, set Contents to Read and write. No other permission is required.
  4. Give it an expiry you are comfortable with, generate it, and paste it above.

A token without Contents read access cannot read the community catalog, so publishing will stay blocked.
