How a request is stored

The page reads catalog/asset-requests.jsonl, checks for your duplicate, then appends one newline-terminated JSON object with a single commit. The file is public and append-only; there are no counts in it.

Kept in this tab's sessionStorage only. It is sent only to api.github.com and is never placed in the URL, localStorage, logs or error text. Create a fine-grained token.

Account and repository write access are checked before submitting is enabled.
How to create the token
  1. Open github.com/settings/personal-access-tokens/new.
  2. Set Repository access to Only select repositories, then choose MeesaAssetLibrary only.
  3. Under Permissions, set Contents to Read and write. No other permission is required.
  4. Generate the token, paste it above, and connect. The page checks GET /user and GET /repos/MeesaJarJar/MeesaAssetLibrary and requires permissions.push.

A token limited to another repository, or one without Contents read access, cannot read or append the queue.
