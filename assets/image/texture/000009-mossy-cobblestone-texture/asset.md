# Mossy Cobblestone Texture

Seamless 768x768 top-down cobblestone with wet grey stones and green moss packed into the joints, generated prompt-only with a seamless model patch. Use for forest ruins, dungeon floors and overgrown paths; tiles cleanly on both axes at 1x, and the matching normal/height maps came from the same run.
- Use for: tileset
- Technical: width=768, height=768, alpha=false, tileable=null, palette=null
- Notes: ComfyUI 05-seamless_texture workflow, DreamShaper 8, prompt-only (no input image), seed 424242, 28 steps, 768x768. Albedo map; normal, height and curvature maps were produced in the same run and are not stored in this bundle yet.
