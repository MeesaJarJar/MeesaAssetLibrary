# Mossy Forest Palette

Eight named hex swatches with RGB values for wet stone, bark and undergrowth under cool overcast light, plus contrast checks.
Use as the starting palette for ground, foliage and stone in ruins or forest exteriors; copy the hexes straight into themes.
Bark Brown is the only warm hue, so this is not a full UI system: it has no error, warning or accent colours.
Keep the dark-to-light ramp order from Deep Canopy to Mist; Stone Grey matches IMG-TILE-000001 and Mist doubles as fog and text.
Load it only when colour decisions matter; each asset already embeds its own technical.palette.
