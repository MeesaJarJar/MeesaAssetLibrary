# UI Confirm Blip

0.22 s two-tone confirmation blip: 880 Hz then 1320 Hz, phase-continuous, with a 3 ms attack and a cosine fade to true zero.
Use for menu accept, purchase confirm, waypoint set or any positive acknowledgement that should feel quick and unobtrusive.
Wrong mood for errors, damage or cancellation, which want a lower, shorter tone with no upward interval.
Mono 22050 Hz 16-bit PCM with a peak near -4 dBFS; plays everywhere and leaves headroom for music.
Tone hand-off sits at 0.11 s and the tail is silent, so it can retrigger without clicks.
